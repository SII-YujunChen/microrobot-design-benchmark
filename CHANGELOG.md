# Changelog

## 3.0.0 — 2026-11-23

- Replaced the Q701–Q800 data interpretation cases from v2.1.0 with 100 original biological microrobot design briefs.
- Organized the briefs into four design topics. Each has its own four-point scoring key and an example alternative architecture.
- Q001–Q700 retain their earlier records. Scores or answers for Q701–Q800 from v2.1.0 apply only to that archived release. Cite the version and question hash when referring to these IDs.

## 2.1.0 — 2026-11-23

- Added Q701–Q800, an English-language challenge collection with 100 self-contained synthetic data cases in four topic areas.
- Added a question-only download and an evaluator key with four case-specific scoring criteria and accepted alternatives for each item.
- Extended the combined dataset and offline validator to 800 questions. Q001–Q700 retain their v2.0.0 records.

## 2.0.0 — 2026-11-23

- Published 700 English questions in seven collections. This edition translates the original Chinese prompts and evaluator notes and preserves the source question IDs.
- Added Q001–Q200 for component retrieval, evidence assessment, and scenario reasoning, and Q301–Q700 for extended scenario design across 40 topics.
- Added collection pages and downloads, task-specific evaluator references, and the original 20-point rubric for Extended Scenario Design.
- Changed the prompt language to `en` and the category display field to `category_label_en`. Each row carries separate checksums for the English prompt and its Chinese source.
- Use the v1.0.0 tag for the original public Q201–Q300 release. Record the prompt language when comparing evaluation runs.

## 1.0.0 — 2026-09-20

- Release the original 100 Chinese prompts Q201–Q300 in JSONL and CSV.
- Add stable IDs, subset metadata, normalized categories, question hashes and a browsable question list.
- Preserve source evaluator metadata and both original 10-point rubric definitions.
- Add a dataset card, evaluation guidance, schema, provenance and offline validation.
