# 生物微机器人设计测试题 Q201–Q300

本页题干与规范 JSONL 一致。标题用于浏览，原始题号保持不变。

## 基础设计 Q201–Q250

### Q201 肿瘤缺氧定位

分类：肿瘤微环境

我想设计一个进入肿瘤微环境后能判断是否处在缺氧区域的生物微机器人。请给出高层生物电路方案：需要哪些 sensing、control、memory、reporter/output 模块？哪些模块不是必须的？

### Q202 瞬时暴露记录

分类：肿瘤微环境

如果机器人只短暂经过肿瘤特征信号区域，但我希望之后还能知道它曾经到达过那里，应该如何设计感知-记忆-表达模块？请说明为什么 memory 比单纯 reporter 更适合。

### Q203 多信号过滤

分类：肿瘤微环境

我希望微机器人只在同时满足低氧和酸性两个肿瘤相关条件时才输出信号。请拆解成生物电路设计方案，并判断它是否更像 Cello-compatible 的组合逻辑，还是需要额外 memory 模块。

### Q204 治疗输出审查

分类：肿瘤微环境

我想做一个肿瘤区域激活的治疗型生物微机器人，但现在只需要设计审查，不要实验步骤。请判断应优先设计哪些感知、控制、表达、安全模块，并指出哪些证据必须补齐后才能推进。

### Q205 免疫联合场景

分类：肿瘤微环境

如果微机器人用于辅助免疫治疗，而不是直接杀伤肿瘤，请从生物电路层面设计一个只做定位、记录和低风险报告的方案。请说明哪些 therapeutic output 不应在早期 demo 中使用。

### Q206 外场触发与生物电路分层

分类：肿瘤微环境

我希望用磁场或热刺激作为外部触发，同时让细菌内部电路记录被触发过的状态。请区分物理驱动层和遗传电路层分别负责什么。

### Q207 假阳性控制

分类：肿瘤微环境

如果普通炎症组织也会出现部分肿瘤类似信号，如何设计一个减少假阳性的生物机器人电路？请考虑多输入逻辑、阈值判断、memory 是否必要和 limitations。

### Q208 安全退出

分类：肿瘤微环境

设计一个在目标区域外应保持沉默、在目标区域内才报告状态的肿瘤微机器人。请重点说明 safety/off-state 控制模块和 output 模块，而不是具体实验流程。

### Q209 肠道炎症感知

分类：肠道监测

我想设计一个肠道生物微机器人，用于区分正常肠道环境和炎症状态。请从 sensing、logic、reporter、containment 角度给出高层电路方案。

### Q210 菌群通信输入

分类：肠道监测

如果任务是让工程菌机器人感知周围菌群密度，再决定是否表达报告信号，应该如何构造 quorum sensing input、control 和 output 模块？memory 是否必要？

### Q211 短期诊断 vs 长期驻留

分类：肠道监测

肠道诊断机器人如果只需要短期检测，与需要长期驻留监测相比，生物电路设计有什么不同？请说明是否需要 memory、kill switch 或长期表达控制。

### Q212 底盘不匹配判断

分类：肠道监测

我想把一个 E. coli 里验证过的 sensor-memory 电路直接迁移到 Bacteroides 底盘做肠道机器人。请给出设计审查：哪些模块可参考，哪些不能直接外推？

### Q213 疾病状态记录

分类：肠道监测

请设计一个能记录肠道中曾经出现过某种炎症相关信号的机器人电路。输出只需要低风险 reporter，不需要治疗输出。

### Q214 多条件触发

分类：肠道监测

如果只有在肠道低氧状态和特定代谢物同时出现时才触发输出，请设计一个高层逻辑电路，并说明 Cello 是否可能用于其中的组合逻辑子模块。

### Q215 群体协同

分类：肠道监测

设计一个肠道群体机器人方案：单个细胞只做局部感知，群体层面通过通信决定是否报告。请拆解 QS communication、local sensor、collective control 和 output。

### Q216 创面感染识别

分类：感染与创面

我想设计一个用于创面感染早期识别的生物微机器人。它应感知感染相关环境变化，并输出可检测信号。请给出模块级设计，不要实验 SOP。

### Q217 病原 QS 信号

分类：感染与创面

如果希望机器人检测病原菌群体通信信号来判断感染风险，应如何设计 QS sensing、signal filtering 和 reporter 模块？请指出误判风险。

### Q218 生物膜场景

分类：感染与创面

面对生物膜感染，机器人需要判断自己是否处于 biofilm-like 环境。请设计高层 sensing-control-output 方案，并说明哪些 biofilm 证据不能直接等同于机器人可控性。

### Q219 局部记录

分类：感染与创面

我希望机器人在经历过感染信号后，即使离开局部区域也能保留状态，方便后续读取。请设计 memory 和 readout 逻辑。

### Q220 治疗输出风险

分类：感染与创面

请评估一个创面感染治疗型生物机器人方案：需要哪些感知、控制、表达和安全模块？哪些治疗输出只能作为未来方向，不能在低风险 demo 中展开？

### Q221 多病原区分

分类：感染与创面

如果要区分普通炎症、细菌感染和真菌感染三类场景，生物电路层面应该如何设计多输入判断？请说明哪些部分更适合做高层概念而不是直接实现。

### Q222 血栓环境识别

分类：血管与血栓

我想设计一个识别血栓相关微环境的生物微机器人，只做定位和报告，不做治疗。请拆解 sensing、control、output 和安全边界。

### Q223 流动环境记忆

分类：血管与血栓

在流动环境中，机器人可能短暂接触目标信号。请设计一个 transient signal capture + memory + reporter 的高层电路方案。

### Q224 非目标组织沉默

分类：血管与血栓

血管内机器人容易经过非目标组织，如何设计一个默认沉默、遇到特定组合信号才报告的电路？请考虑 AND/NOT logic 和 safety。

### Q225 外场导航和遗传输出

分类：血管与血栓

如果导航由磁驱动完成，生物电路只负责目标识别和状态报告，请给出分层设计方案，避免把运动控制和基因表达混为一谈。

### Q226 水体污染检测

分类：环境监测

设计一个用于水体污染检测的生物微机器人。它需要感知污染物并输出可读信号，但不应扩展到开放环境释放方案。请给出模块级设计和安全边界。

### Q227 重金属暴露记录

分类：环境监测

如果任务是记录水体中是否曾经出现过重金属暴露，而不是实时检测，请设计 memory-based biosensing robot 的高层方案。

### Q228 多污染物分类

分类：环境监测

我想让环境监测机器人区分有机污染、重金属和营养盐异常三类信号。请设计 sensing 和 output 编码策略，不需要具体工程步骤。

### Q229 封闭检测装置

分类：环境监测

如果机器人只在封闭微流控芯片内做环境样本检测，和开放水体释放相比，电路设计和安全模块有什么不同？

### Q230 群体阈值报警

分类：环境监测

设计一个只有当污染信号在多个微机器人中持续出现时才报警的群体阈值系统。请考虑 local sensor、QS communication、memory 和 output。

### Q231 发酵状态监测

分类：工业生物制造

我想设计一个在发酵过程中监测代谢状态的生物微机器人。请说明哪些 sensing、metabolic state reporter、memory 或 feedback control 模块可能需要。

### Q232 资源负担审查

分类：工业生物制造

如果一个机器人电路包含 sensor、logic、memory 和 strong reporter，如何从设计层面评估资源负担风险？请给出审查逻辑，而不是实验优化参数。

### Q233 Yarrowia 场景

分类：工业生物制造

请为 Yarrowia lipolytica 代谢工程场景设计一个高层监测机器人：它应感知代谢状态并报告异常，但不要假设 E. coli 模块可以直接迁移。

### Q234 产物积累记忆

分类：工业生物制造

如果希望细胞机器人记录某个产物曾经达到过高水平，请设计 sensing-memory-readout 方案，并说明它和实时 reporter 的差别。

### Q235 反馈控制边界

分类：工业生物制造

我想让机器人根据代谢负担自动调低表达强度。请设计一个概念性的 feedback control 电路，并判断 Cello 2.0 是否适合直接编译这种反馈系统。

### Q236 组织支架定位

分类：组织工程与生物材料

设计一个用于组织工程支架中的生物微机器人，它需要感知自己是否处于材料内部并输出定位信号。请拆解材料感知、控制和 reporter 模块。

### Q237 空间图案形成

分类：组织工程与生物材料

如果想让细胞机器人在材料中形成空间图案，而不是均匀表达，请设计一个高层 spatial control 方案，考虑局部信号、通信和输出模块。

### Q238 材料修复指示

分类：组织工程与生物材料

我想让机器人在材料损伤或应力变化时报告状态。请给出可能的 sensing-memory-output 设计思路，并明确哪些信号目前可能缺乏直接证据。

### Q239 长期表达控制

设计一个根际环境中的生物微机器人，用来感知植物根系相关信号并报告土壤状态。请考虑底盘、sensor、output 和环境安全。

### Q241 病原预警

分类：农业与土壤

如果任务是提前预警植物病原感染，而不是进行干预治疗，请设计低风险感知和报告电路，并说明如何避免过度推断。

### Q244 群体投票

设计一个生物微机器人群体投票系统：单个机器人感知局部信号，群体通过通信决定是否输出全局报告。请拆解 local sensing、communication、threshold control 和 output。

## 场景设计 Q251–Q300

### Q251 实体瘤低氧事件记忆

分类：肿瘤微环境

我想设计一种用于实体瘤区域驻留的细菌微机器人，它需要在低氧环境中被激活，并在离开低氧区域后保持一段时间的“到达肿瘤”状态记录。请给出完整的生物电路设计方案，包括感知模块、记忆模块、输出模块、安全控制模块，并评价该方案的可行性和主要风险。

### Q252 肿瘤微环境多信号记录

分类：肿瘤微环境

设计一个用于肿瘤微环境监测的生物微机器人，不直接杀伤肿瘤，只负责记录它是否经历过酸性、低氧和炎症信号。请判断是否需要多输入逻辑门、是否需要记忆模块，以及最终应采用什么低风险输出方式。

### Q253 外场导航与局部激活分层

分类：肿瘤微环境

我希望设计一个“先导航、后激活”的肿瘤治疗型生物机器人：在外场引导到目标区域前保持沉默，到达肿瘤区域后才允许表达功能蛋白。请给出高层生物电路结构，并说明外部控制信号和内源性肿瘤信号应如何分工。

### Q254 炎症与肿瘤多信号判别

分类：肿瘤微环境

设计一个可以区分“普通炎症组织”和“肿瘤组织”的生物微机器人。它不能只依赖单一信号，需要综合多个环境输入。请设计 sensing + logic + output 架构，并说明哪些输入信号容易产生误判。

### Q255 肿瘤复发信号长期记录

分类：肿瘤微环境

我想做一个肿瘤复发监测型微生物机器人，它不需要治疗，只需要在体内感知到复发相关信号后形成可读出的长期记录。请设计适合的感知、记忆和报告模块，并评价长期记忆对宿主负担和安全性的影响。

### Q256 免疫微环境低风险报告

分类：肿瘤微环境

设计一个用于肿瘤局部免疫微环境分析的生物微机器人，它需要判断是否处于免疫抑制环境，并输出一个低风险 reporter。请说明应选择哪些类别的输入信号、是否需要逻辑门、是否需要记忆，以及如何避免过度推断治疗效果。

### Q257 三条件联合触发输出

分类：肿瘤微环境

我希望构造一个只在“低氧 + 高乳酸 + 外部触发信号”同时满足时才启动输出的肿瘤生物机器人。请给出模块级设计，并判断这种三条件系统相比双条件系统的优势和代价。

### Q258 肿瘤间质间接感知

分类：肿瘤微环境

### Q259 肠道炎症短时报告

分类：肠道监测

我想设计一个用于炎症性肠病监测的肠道细菌机器人，它需要感知炎症相关信号，并在短时间内输出可检测 reporter。请设计电路架构，并判断是否需要长期记忆模块。

### Q260 持续炎症时间过滤

分类：肠道监测

设计一个肠道驻留型活体药物机器人，它需要区分暂时性饮食扰动和持续性炎症状态，只有持续异常时才启动输出。请设计 sensing、temporal filtering、memory 或 logic 模块，并说明注意事项。
